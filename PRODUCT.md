# Требования учебного продукта
R1. Аудитория не может иметь два подтверждённых бронирования с пересекающимися интервалами одного дня. Смежные интервалы 10:00–11:00 и 11:00–12:00 разрешены.
R2. Пользователь видит свои записи. Администратор видит все записи. Экспорт в текущей версии отсутствует.
R3. В записи есть id, room, date, start, end, owner и status. Допустимые статусы: pending, confirmed, cancelled.
R4. Время задаётся HH:MM по местному времени колледжа для указанной даты; end позже start. Поддержка перехода через полночь вне учебной области.
R5. Первая итерация должна устранить подтверждённое нарушение R1 и сделать понятным формат данных. Новые функции включаются только после уточнения критериев приёмки.
